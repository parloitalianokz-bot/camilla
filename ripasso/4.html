Вынесение общего множителя

Упражнения 26–28 · Разложение на множители и решение уравнений

📐 Основные свойства

В этих упражнениях мы решаем уравнения, разложив левую часть на множители. Вот ключевые приёмы:

  • Общий множитель. Если в каждом слагаемом есть одна и та же переменная или число, его можно вынести за скобки: ax + bx = x(a + b) или ax² + bx = x(ax + b).
  • Произведение равно нулю. Если A · B = 0, то либо A = 0, либо B = 0 (или оба). Это позволяет находить все корни уравнения.
  • Уравнения вида ax² = b. Переносим свободный член, делим на коэффициент при x² и извлекаем квадратный корень (с учётом ±): x = ±√(b/a) (если b/a ≥ 0).
26

Упражнение 26 · вынесение x

26.1 с решением
x² − 3x = 0
1

Вынесем общий множитель x за скобки:

x(x − 3) = 0
2

Произведение равно нулю → каждый множитель может быть равен нулю:

x = 0   или   x − 3 = 0
3

Решаем второе уравнение:

x − 3 = 0  ⇒  x = 3
4

Ответ:

x = 0   или   x = 3
26.2 самостоятельно
5x + 2x² = 0

Введите оба корня (порядок не важен):

Решение

1. Вынесем общий множитель x:

x(5 + 2x) = 0

2. x = 0  или  5 + 2x = 0

3. 2x = −5  ⇒  x = −5/2 = −2,5

Ответ: x = 0  или  x = −2,5

26.3 самостоятельно
0,7x − 1,4x² = 0

Введите оба корня:

Решение

1. Вынесем общий множитель 0,7x:

0,7x (1 − 2x) = 0

2. 0,7x = 0  ⇒  x = 0

3. 1 − 2x = 0  ⇒  2x = 1  ⇒  x = 0,5

Ответ: x = 0  или  x = 0,5

Упражнение 27 · уравнения вида ax² = b

27.1 с решением
¼x² − 1 = 0
1

Перенесём свободный член в правую часть:

¼x² = 1
2

Умножим обе части на 4:

x² = 4
3

Извлечём квадратный корень (не забываем ±):

x = ±√4  ⇒  x = ±2
4

Ответ:

x = 2  или  x = −2
27.2 самостоятельно
⅛x² − 3 = 0

Введите оба корня:

Решение

1. ⅛x² = 3

2. x² = 3 · 8 = 24

3. x = ±√24 = ±2√6

Ответ: x = 2√6  или  x = −2√6  (или ±√24)

27.3 самостоятельно
0,2 − 1,8x² = 0

Введите оба корня:

Решение

1. −1,8x² = −0,2  ⇒  1,8x² = 0,2

2. x² = 0,2 / 1,8 = 2/18 = 1/9

3. x = ±√(1/9) = ±1/3

Ответ: x = 1/3  или  x = −1/3

Упражнение 28 · более сложное разложение

28.1 самостоятельно
(2x − 1)·(3x + 5) − (2x − 1)·5x + 7(2x − 1) = 0

Вынесите общий множитель (2x − 1) и найдите все корни:

Решение

1. Общий множитель — (2x − 1):

(2x − 1)·[(3x + 5) − 5x + 7] = 0

2. Упростим выражение в скобках: 3x + 5 − 5x + 7 = −2x + 12

(2x − 1)(−2x + 12) = 0

3. 2x − 1 = 0  ⇒  x = 1/2

4. −2x + 12 = 0  ⇒  2x = 12  ⇒  x = 6

Ответ: x = 0,5  или  x = 6

28.2 самостоятельно
(4x − 3)·(3x − 9) − (4x − 3)·7x + 5(4x − 3) = 0

Вынесите общий множитель (4x − 3) и найдите все корни:

Решение

1. Общий множитель — (4x − 3):

(4x − 3)·[(3x − 9) − 7x + 5] = 0

2. Упростим: 3x − 9 − 7x + 5 = −4x − 4

(4x − 3)(−4x − 4) = 0

3. 4x − 3 = 0  ⇒  x = 3/4 = 0,75

4. −4x − 4 = 0  ⇒  −4x = 4  ⇒  x = −1

Ответ: x = 0,75  или  x = −1

💡 Совет: Всегда проверяй ответы подстановкой в исходное уравнение. Если получилось 0 = 0 — корень верный. Не забывай про знак ± при извлечении квадратного корня!
